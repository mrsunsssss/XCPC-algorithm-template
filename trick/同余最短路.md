给定若干数字 $x_i$ 。每次询问给出 $y$ ，问是否存在 $\sum\limits_{i=1} c_ix_i = y$ ，其中 $c_i\ge  0$ 。

定义 $dp_i$ 表示最小的使得 $x\mod P = i$ 的数 $x$ 。 处理完后，每次询问比较 $dp_{y \mod P}$ 与 $y$ 的大小即可。 $P$ 不妨取 $x_i$ 中的最小值。

这里介绍同于最短路转圈做法。

根据裴蜀定理：

存在整数 $x,y$ ，使得 $ax + by = gcd(a,b)$ 。两边同时对 $b$ 取模，得到 $ax\mod b =  gcd(a,b) \mod b$

此时如果 $x$ 是负数，可以通过加任意个 $b$ 变成非负整数。那么此时，存在非负整数 $x$ ,使得 $ax\equiv gcd(a,b) (\mod b)$ 。并且根据裴属定理，其他结果都是 $gcd(a,b)$ 的倍数。此时将 $x$ 乘上 $y$ ，得到的结果即为 $y\cdot gcd(a,b) \mod b$ 。而 $b\mod gcd(a,b) = 0$ ，故 此时不同的结果就是 $\frac{b}{gcd(a,b)}$ ，即环长。

那么对于 $(ax + y) \mod b$ ，就会形成 $b/\frac{b}{gcd(a,b)} = gcd(a,b)$ 个环。

然后我们即可对于所有子环，找到其中最小的位置，从这个位置开始转移一圈。或者直接转移两圈，写起来更方便。

```C++
sort(a.begin(), a.end());
int mod = a[0];
vector<int> dp(mod, inf);dp[0] = 0;//dp[i]表示最小的x使得 x % mod = i
for (int i = 0;i < a.size();i++) {
    for (int j = 0, cnt = gcd(a[i], mod);j < cnt;j++) {
        for (int k = j, p = 0;p < 2;p += (k == j)) {
            dp[(k + a[i]) % mod] = min(dp[(k + a[i]) % mod], dp[k] + a[i]);
            k = (k + a[i]) % mod;
        }
    }
}
```
